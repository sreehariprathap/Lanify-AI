## Environment Setup

### Requirements

- **Python:** Version 3.9 or higher
- **Virtual Environment:** Recommended for dependency isolation
- **Docker:** Required for running the development database

---

## Installation

1. **Build the Docker Image**

   Open your terminal and navigate to the Docker directory:
   ```
   cd dev/docker
   ```
   Build the Docker image without caching:
   ```
   docker build --no-cache -f docker-compose.yml -t lanify-backend .
   ```

2. **Navigate to the Codebase**

   Ensure you are in the root directory of the codebase:
   ```
   cd ../
   ```

3. **Create and Activate a Virtual Environment**

   Choose one of the options below:

   - **Using venv (Python Standard Library)**
     ```bash
     python -m venv venv
     # On macOS/Linux:
     source venv/bin/activate
     # On Windows:
     venv\Scripts\activate
     ```

   - **Using conda**
     ```bash
     conda create --name lanify python=3.9
     conda activate lanify
     ```

4. **Install Python Dependencies**

   Install the required Python packages:
   ```bash
   pip install -r requirements.txt
   ```

5. **Apply Database Migrations**

   Initialize the database schema:
   ```bash
   flask db upgrade
   ```

## Running the Application

1. **Start the Development Database**

   Ensure the database is running. If it is not, start it using Docker:
   ```bash
   docker compose -f docker-compose/dev.yml up -d
   ```

2. **Run the Application**

   Launch the backend server:
   ```bash
   python app.py
   ```
   The application will be available at [http://localhost:3000/](http://localhost:3000/).

3. **Access API Documentation**

   View the API documentation at:
   [http://localhost:3000/swagger-ui](http://localhost:3000/swagger-ui)

---

## Stopping the Application

1. **Stop the Application**

   To stop the application, press `Ctrl+C` in the terminal where it is running.

2. **Stop the Development Database**

   Shut down the Docker container with:
   ```bash
   docker compose -f docker-compose/dev.yml down
   ```
   To also remove the persisted data volume, add the `-v` flag:
   ```bash
   docker compose -f docker-compose/dev.yml down -v
   ```

```
dev/
├── app.py               # Entry point of the application

│   ├── db.yml          # Database configuration
│   └── docker-compose.yml  # Development environment configuration
├── migrations/          # Database migration files (auto-generated by Flask-Migrate)
├── models/              # Database models
└── service/             # Business logic layer
```

## Database Management

Ensure you are in the project root (`dev/`) when running the following commands.

### Create a Migration File

Whenever you add, remove, or modify a model, generate a new migration file:
```bash
flask db migrate -m "Describe your changes here"
```

### Apply Migrations

Upgrade the database schema by running:
```bash
flask db upgrade
```

> Note: Always run migrations after pulling updates to keep the database schema up-to-date.

### Rollback Migrations

If necessary, you can revert to a previous migration:
```bash
flask db downgrade
```

### Check Migration Status

To view the current migration version:
```bash
flask db current
```

### View Migration History

To see the full migration history:
```bash
flask db history
```
